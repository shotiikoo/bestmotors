# Best Motors — საიტი და ადმინ პანელი

- `/` — მაღაზიის საიტი (კატალოგი, კალათა, შეკვეთა, VIN ძებნა, ფილიალები, კონტაქტი)
- `/admin` — ადმინ პანელი (შეკვეთები, პროდუქტები, მოთხოვნები, ფილიალები, პარამეტრები)

სერვერს დამატებითი პაკეტები არ სჭირდება, საკმარისია Node.js 18 ან უფრო ახალი.

## ლოკალურად გაშვება

```bash
ADMIN_PASSWORD=შენი_პაროლი node server.js
```

შემდეგ გახსენი http://localhost:3000 და http://localhost:3000/admin

## Render-ზე განთავსება

1. ატვირთე ეს საქაღალდე GitHub-ის რეპოზიტორიაში.
2. Render-ზე შექმენი **New → Web Service** და აირჩიე რეპოზიტორია.
3. პარამეტრები:
   - **Build Command:** `npm install`
   - **Start Command:** `node server.js`
4. **Environment** განყოფილებაში დაამატე:
   - `ADMIN_PASSWORD` — ადმინ პანელის პაროლი (გამოიყენე ძლიერი პაროლი)
   - `DATA_DIR` — `/var/data`
5. **Disks** განყოფილებაში დაამატე დისკი, Mount Path: `/var/data`, ზომა 1 GB.

**მნიშვნელოვანი:** დისკის გარეშე Render ყოველ გადატვირთვაზე შლის ფაილებს, ანუ დაიკარგება შეკვეთები, პროდუქტები და სურათები. დისკი ხელმისაწვდომია ფასიან გეგმაზე (Starter). უფასო გეგმა გამოდგება მხოლოდ საცდელად.

## მონაცემები

- ყველაფერი ინახება `DATA_DIR/db.json` ფაილში, სურათები კი `DATA_DIR/uploads/` საქაღალდეში.
- პირველ გაშვებაზე `db.json` ივსება `data/seed.json`-იდან, სადაც სანიმუშო პროდუქტები და ფილიალებია. ისინი ადმინ პანელიდან შეცვალე ან წაშალე.
- სარეზერვო ასლისთვის საკმარისია `db.json` ფაილისა და `uploads` საქაღალდის დაკოპირება.

## როგორ მუშაობს

- **შეკვეთები:** მყიდველის შეკვეთა სერვერზე ინახება და ადმინ პანელში ჩანს. პანელი ყოველ 30 წამში ახლდება, ახალი შეკვეთის რაოდენობა კი ბრაუზერის ჩანართის სათაურშიც ჩანს.
- **ფასები:** შეკვეთის ჯამს სერვერი ითვლის ბაზაში შენახული ფასებით, ამიტომ ბრაუზერიდან ფასის გაყალბება შეუძლებელია.
- **მარაგი:** როცა შეკვეთას „შესრულებულს“ მონიშნავ, მარაგი შესაბამის ფილიალში ავტომატურად მცირდება. თუ სტატუსს უკან შეცვლი, მარაგი ბრუნდება.
- **VIN:** საიტი VIN-ს ჯერ თავად შიფრავს, შემდეგ კი სერვერი ამოწმებს აშშ-ის ოფიციალურ ბაზაში (NHTSA, უფასო), საიდანაც ზუსტი მოდელი მოდის. ეს ბაზა ამერიკული ბაზრის მანქანებისთვის მუშაობს.
- **უსაფრთხოება:** ადმინის სესია 12 საათი გრძელდება. პაროლის გამოცნობის მცდელობები შეზღუდულია: 15 წუთში 8 მცდელობა ერთი მისამართიდან.
